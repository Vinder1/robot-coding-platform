## 1. Назначение проекта
Разработать веб-платформу для обучения и соревнований по программированию робота на специальном языке программирования.

Пользователи должны иметь возможность писать алгоритмы управления роботом, запускать их на виртуальной карте и решать подготовленные администраторами задачи.

## 2. Основной функционал
2.1. Работа с кодом
- Предоставить пользователю редактор для написания кода на специальном языке программирования.
- Реализовать интерпретатор языка с поддержкой команд движения, поворотов, условий и циклов.
- Предоставить песочницу для свободного запуска и тестирования алгоритмов.
- Отображать перемещение робота по карте с возможностью просмотра выполнения программы.

2.2. Испытания
- Предоставить каталог обучающих и соревновательных уровней.
- Реализовать создание и редактирование испытаний администраторами.
- Каждое испытание должно содержать карту, начальную позицию робота, препятствия и целевое условие.
- Пользователь должен иметь возможность отправить решение на проверку.
- Система должна определять, успешно ли робот выполнил поставленную задачу.
- Предоставить возможность просмотра рейтинга с указанием пользователя, количества итераций.

2.3. Пользователи и администрирование
- Реализовать регистрацию, авторизацию и управление профилем пользователя.
- Предусмотреть разграничение прав пользователей и администраторов.
- Предоставить администраторам возможность управления пользователями и испытаниями.

## 3. Архитектура системы
Система должна состоять из следующих компонентов:
- Frontend: веб-интерфейс на Vue.js и TypeScript, редактор кода, визуализация карты и робота, страницы испытаний и рейтингов.
- Backend: ASP.NET Core Web API, отвечающий за бизнес-логику, пользователей, испытания и результаты решений.
- Robot Executor: отдельный исполнитель, отвечающий за интерпретацию и выполнение пользовательского кода, а также проверку результатов.
- Message Broker: RabbitMQ и MassTransit для асинхронного взаимодействия между backend и исполнителем.
- Database: PostgreSQL для хранения пользователей, испытаний, решений и результатов выполнения.

## 4. Основной сценарий работы
- Пользователь авторизуется на платформе.
- Выбирает испытание или открывает песочницу.
- Пишет программу управления роботом.
- Запускает программу или отправляет решение на проверку.
- Backend передаёт задачу исполнителю через брокер сообщений.
- Исполнитель выполняет программу и возвращает результат проверки.
- Backend сохраняет результат и обновляет информацию о решении.
- При успешном прохождении испытания результат учитывается в рейтинге.
- Пользователь может просмотреть своё положение и результаты других участников.

## 5. Технические требования
- Клиентская часть: Vue.js, TypeScript.
- Серверная часть: C#, ASP.NET Core.
- Исполнитель: .NET.
- База данных: PostgreSQL.
- Брокер сообщений: RabbitMQ, MassTransit.
- Контейнеризация и запуск инфраструктуры: Docker, Docker Compose.
- OpenSearch


## 6. Статистика и OpenSearch
Администраторам доступна вкладка «Статистика» и API `api/statistics`:
- сводные показатели по попыткам решений.
- статистика в разрезе испытаний.
- выгрузка CSV (сводка или детализация попыток).
- состояние кластера OpenSearch.
- поиск по проиндексированным попыткам.
- переиндексация попыток из PostgreSQL.

## 7. Ожидаемый результат
Готовая веб-платформа, позволяющая пользователям обучаться программированию на специальном языке управления роботом, решать логические и алгоритмические задачи, соревноваться друг с другом и получать оценку эффективности написанных решений.
